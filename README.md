# Adventurer Village Prototype

一个“星露谷式生活经营 + 猎魔村式冒险者村庄管理”的 2D 游戏原型。

当前版本目标是先验证最小闭环：

`种药草 → 制作小药水 → 冒险者购买 → 出村讨伐 → 带回材料 → 升级药剂店`

## 当前版本

版本：v0.1 prototype

当前已实现：

- 可操作主角，支持 8 方向移动。
- 轻 45 度风格的家园占位场景。
- 基础建筑、树木、污染边界和碰撞。
- 农田流程：开垦、播种、浇水、成熟、收获。
- 工具栏：锄头、种子、水壶、斧头、短剑、物理技能、法术技能。
- 滚轮或数字键切换工具。
- 斧头砍树、短剑挥砍、物理冲击、星火法术占位动作。
- 昼夜轮替效果。

## 运行方式

最快方式：双击 `play_game.bat`。

1. 打开 Godot 4。
2. 选择 `Import`。
3. 选择本目录下的 `project.godot`。
4. 打开项目后点击运行。

如果使用命令行验证项目可加载：

```powershell
godot_console.exe --headless --path . --quit
```

## 操作说明

- `WASD` 或方向键：8 方向移动。
- 鼠标滚轮或 `1-7`：切换当前工具/技能。
- 鼠标左键或 `空格`：使用当前工具/技能。
- 农田流程：锄头开垦 → 种子播种 → 水壶浇水 → 成熟后靠近收获。
- 斧头可以砍树并获得木材。
- 短剑、物理技能、法术技能目前是动作占位，用于确定主角战斗手感方向。

## 当前美术方向

- 视角：轻 45 度俯视表现，底层逻辑仍保持 2D 俯视/网格友好。
- 风格暂名：灯火边境 / Lantern Frontier。
- 核心气质：温暖废土童话、生物异变、幸存者安全区、夜晚防守。
- 关键对比：村庄内的温暖灯光与村外污染生态形成强对比。
- 概念图目录：`art/concepts/` 与 `art/style-exploration/`。
- 运行时资产必须遵守 `AGENTS.md` 中的 `agent-sprite-forge` 生产规则，并在 `art/production-runs/` 留下记录。

## 当前原则

- 先做闭环，再做内容。
- 先用占位图，再做正式美术。
- 先做一个冒险者，再做多个冒险者。
- 先做一个建筑，再做完整村庄。
- 先做结算战斗，再考虑实时战斗。
- 家园阶段先做移动、农田、工具和技能手感，暂不做怪物攻城。
