# Adventurer Village Prototype

一个“星露谷式生活经营 + 猎魔村式冒险者村庄管理”的 2D 游戏原型。

当前版本目标是先验证最小闭环：

`种药草 → 制作小药水 → 冒险者购买 → 出村讨伐 → 带回材料 → 升级药剂店`

## 当前版本

版本：v0.1 prototype

当前已实现：

- 4 块农田。
- 点击农田播种药草。
- 药草成熟后点击收获。
- 用 `2 药草` 制作 `1 小药水`。
- 药剂店存储小药水。
- 冒险者自动购买小药水。
- 冒险者自动出村讨伐怪物。
- 冒险者返回后带回怪物材料。
- 使用怪物材料和金币升级药剂店。

## 运行方式

最快方式：双击 `play_game.bat`。

1. 打开 Godot 4。
2. 选择 `Import`。
3. 选择本目录下的 `project.godot`。
4. 打开项目后点击运行。

如果使用命令行验证项目可加载：

```powershell
godot_console.exe --headless --path . --quit
```

## 操作说明

- 点击棕色农田：播种药草。
- 药草成熟后再次点击农田：收获药草。
- 点击 `制作小药水` 按钮：把药草制作成药水并放入药剂店库存。
- 冒险者会自动购买药水、出村、返回并带回材料。
- 材料和金币足够时，点击 `升级药剂店`。

## 当前美术方向

- 视角：轻 45 度俯视表现，底层逻辑仍保持 2D 俯视/网格友好。
- 风格暂名：灯火边境 / Lantern Frontier。
- 核心气质：温暖废土童话、生物异变、幸存者安全区、夜晚防守。
- 关键对比：村庄内的温暖灯光与村外污染生态形成强对比。
- 概念图目录：`art/concepts/` 与 `art/style-exploration/`。

## 当前原则

- 先做闭环，再做内容。
- 先用占位图，再做正式美术。
- 先做一个冒险者，再做多个冒险者。
- 先做一个建筑，再做完整村庄。
- 先做结算战斗，再考虑实时战斗。
