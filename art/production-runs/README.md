# Production Runs

Every runtime art asset generated for this project must have a production run record in this folder.

Records are required for auditability. They prove which `agent-sprite-forge` skill was used, which prompt was used, which raw files were generated, what postprocessing happened, and how the asset was integrated into Godot.

Concept-only images do not need a record here, but they must remain in `art/concepts/` or `art/style-exploration/` and must not be treated as final runtime assets.
